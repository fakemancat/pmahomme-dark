# pmahomme-dark

[English version](README.md)

Тёмная графитовая тема для phpMyAdmin, созданная на основе стандартной темы `pmahomme`.

Это независимый проект сообщества, а не официальный выпуск phpMyAdmin. Проект
не одобрен и не поддерживается командой phpMyAdmin.

![Предпросмотр pmahomme-dark](screen.png)

## О теме

`pmahomme-dark` сохраняет привычную структуру интерфейса phpMyAdmin и добавляет согласованное тёмное оформление для навигации, таблиц, форм, диалоговых окон, уведомлений, SQL-редактора, консоли, Designer и других основных элементов.

## Совместимость

- phpMyAdmin 5.0, 5.1 и 5.2
- Версия темы: 1.0
- Интерфейсы LTR и RTL

## Установка

1. Скачайте репозиторий через **Code → Download ZIP** или клонируйте его с помощью Git.
2. Убедитесь, что распакованная папка называется `pmahomme-dark`.
3. Скопируйте всю папку в каталог `themes` вашей установки phpMyAdmin:

   ```text
   phpMyAdmin/
   └── themes/
       └── pmahomme-dark/
           ├── css/
           ├── img/
           ├── jquery/
           ├── scss/
           └── theme.json
   ```

4. Откройте phpMyAdmin и выберите **pmahomme-dark** в списке **Theme / Тема** на главной странице.

Не заменяйте и не удаляйте исходную папку `pmahomme`. Новая тема должна быть установлена рядом с ней.

### Использование по умолчанию

Добавьте следующую настройку в `config.inc.php`:

```php
$cfg['ThemeDefault'] = 'pmahomme-dark';
```

Если переключатель тем не отображается, убедитесь, что менеджер тем включён:

```php
$cfg['ThemeManager'] = true;
```

Дополнительная информация доступна в [официальной документации phpMyAdmin по пользовательским темам](https://docs.phpmyadmin.net/en/release_5_2_3/themes.html).

## Обновление

Замените содержимое каталога `themes/pmahomme-dark` файлами новой версии и обновите страницу phpMyAdmin. Если отображаются старые стили, очистите кеш браузера.

## Удаление

Сначала переключитесь на другую тему, затем удалите каталог `themes/pmahomme-dark`. Если вы добавляли параметр `ThemeDefault`, удалите или измените его.
